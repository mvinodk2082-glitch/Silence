Silence

Block ads and trackers across browsers and apps on Android. Silence uses a local VPN as a DNS filter only — your traffic is not sent through our servers.

Download APK Source code Privacy policy

Who it’s for

  • People tired of ads in every app
  • Privacy users who want tracker blocking
  • Anyone who cannot or will not root

How it works

  • Local Android VPN API
  • DNS domain blocklists
  • Optional remote list updates
  • Per-app exclusions (banking, etc.)

Install in 60 seconds

  • Download the latest APK from Releases
  • Allow “Install unknown apps” for your browser/Files
  • Open Silence → Turn protection on → accept VPN
  • Optional: Always-on VPN + unrestricted battery

Honest limits
