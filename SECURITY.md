# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.4.x   | Yes |
| &lt; 0.4 | Best effort |

## Reporting a vulnerability

Please **do not** open a public issue for exploitable VPN/DNS bugs.

1. Email via GitHub Security Advisories on this repository, or  
2. Open a private security advisory:  
   https://github.com/mvinodk2082-glitch/Silence/security/advisories/new

Include: device model, Android version, steps to reproduce, impact.

## Scope notes

- Silence is a **local DNS filter**. It is not an anonymity network.  
- Compromised upstream DNS or malicious blocklist URLs can affect resolution — users choose sources.
